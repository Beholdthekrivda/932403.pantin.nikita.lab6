## Лабораторная работа 6
## Тема: «Список задач» (в памяти) (8 вариант)

## Что нужно было реализовать
С помощью библиотеки express реализовать обработку HTTP запросов GET и POST с помощью веб-сервера node.js, а также service worker, который кеширует статику и обеспечивает работу приложения офлайн
Реализовать маршруты: GET /, GET /about, GET /api/tasks, POST /api/tasks, GET /api/status

## Структура лабораторной
Директория public: index.html - главная страница сайта, about.html - страница /about, style.css - визуал сайта, app.js - скрипт на javascript для обработки команд, sw.js - service worker который кеширует статику
server.js - основной файл конфигурации сервера node.js, в которым прописаны методы обработки запросов по заданным маршрутам

## Как это работает
Пользователь вводит задачу в поле, нажимает добавить, тем самым отправляет POST запрос на сервер
На сервер POST запрос обрабатывается: задача добавляется в массив tasks с уникальным id и статусом completed (true/false)
(Статус completed можно менять с помощью поля галочки на сайте)
Если пользователь переходит по указанным маршрутам (происходит GET запрос), то для каждого из них выводится свой файл (для / и /about это index.html и about.html соответственно, для /api/status json в формате status: "...", message: "...", /api/tasks обрабатывается более детально с проверкой на completedQuery = "true")

## Запуск
npm install
npm start
Сервер доступен на http://localhost:3000
